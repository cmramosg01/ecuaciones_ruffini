La idea: un producto igual a cero

Si un producto vale 0, alguno de sus factores vale 0. Por eso, si conseguimos factorizar el polinomio, basta con igualar a 0 cada factor:

x\,(x - 1)(x^2 - 5x + 6) = 0 \;\left\{\begin{array}{l} x = 0 \\[4pt] x - 1 = 0 \;\rightarrow\; x = 1 \\[4pt] x^2 - 5x + 6 = 0 \;\rightarrow\; x = 2,\; x = 3 \end{array}\right.

Para las ecuaciones de grado 3 y 4 que no son bicuadradas, la herramienta para factorizar es la regla de Ruffini, que ya conoces del tema de polinomios.

El plan, paso a paso

1
¿Factor común? Si no hay término independiente, saca x (o x^2) factor común antes de nada. Te da la solución x = 0 y baja el grado.
2
Buscar raíces enteras entre los divisores del término independiente, positivos y negativos.
3
Ruffini. Si el resto da 0, ese número es raíz y el polinomio baja un grado. Si no, se prueba otro divisor.
4
Cuando queda uno de 2º grado, se resuelve con la fórmula o como incompleta.
5
Reunir todas las soluciones: el 0 del factor común (si lo hubo), las raíces de Ruffini y las de la ecuación de 2º grado.

Ejemplo resuelto (así se escribe en el examen)

Resolver x^3 - 2x^2 - 5x + 6 = 0.

Probamos con los divisores de 6: \pm 1,\; \pm 2,\; \pm 3,\; \pm 6.

1−2−56
−1−132
1−3−28
1−2−56
11−1−6
1−1−60

-1 no es raíz (resto 8). 1 sí es raíz (resto 0). Entonces:

(x - 1)(x^2 - x - 6) = 0 \;\left\{\begin{array}{l} x - 1 = 0 \;\rightarrow\; x = 1 \\[6pt] x^2 - x - 6 = 0 \end{array}\right.
x^2 - x - 6 = 0 \;\rightarrow\; x = \dfrac{1 \pm \sqrt{1 + 24}}{2} = \dfrac{1 \pm 5}{2} \;\rightarrow\; x = 3,\; x = -2
\text{Soluciones: } \; x_1 = 1, \quad x_2 = 3, \quad x_3 = -2

Con factor común primero

Es el ejemplo del libro: x^4 - x^3 - 20x^2 = 0. No hay número suelto, así que no hace falta Ruffini:

x^2\,(x^2 - x - 20) = 0 \;\left\{\begin{array}{l} x^2 = 0 \;\rightarrow\; x = 0 \;(\text{doble}) \\[6pt] x^2 - x - 20 = 0 \;\rightarrow\; x = 5,\; x = -4 \end{array}\right.
No dividas entre x ni entre x^2: perderías la solución x = 0.

Cómo se hace Ruffini

1
Escribe los coeficientes ordenados de mayor a menor grado. Si falta un grado, pon un 0. En x^3 - 7x - 6 los coeficientes son 1,\; 0,\; -7,\; -6.
2
Pon a la izquierda el número que pruebas y baja el primer coeficiente.
3
Multiplica ese número por el último de abajo y escribe el resultado en la columna siguiente. Suma la columna.
4
Repite hasta el final. El último número es el resto. Los demás son los coeficientes del cociente, que tiene un grado menos.
Ojo con el signo del factor: si la raíz es 2, el factor es (x - 2); si la raíz es -3, el factor es (x + 3). Y una raíz puede repetirse: después de dividir, vuelve a probar el mismo número.
